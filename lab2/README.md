# Лабораторна робота №2

Багатопотоковий застосунок на Haskell (GHC з ключем `-threaded`): розв'язання системи лінійних
рівнянь **паралельним методом Гаусса**.

## Алгоритм

Система зберігається як розширена матриця `n × (n+1)` у масиві `IOUArray Int Double` (рядок за рядком).

Прямий хід, для кожного стовпця `k`:
1. **Вибір головного елемента** (послідовно): серед рядків `k…n−1` шукається найбільший за модулем
   елемент у стовпці `k`. Рядок з ним міняється місцями з рядком `k`. Якщо елемент дорівнює нулю
   (менший за 1e−12), матриця вироджена.
2. **Виключення** (паралельно): рядки `k+1…n−1` незалежні один від одного, тому розподіляються між
   `T` потоками з чергуванням. Потік `t` обробляє рядки `k+1+t, k+1+t+T, …`. Для кожного рядка
   `i`: `a[i][j] -= a[i][k] / a[k][k] · a[k][j]`. Потоки запускаються через `forkOn` (кожен на своєму
   ядрі). Головний потік чекає їх через `MVar` перед переходом до наступного стовпця (бар'єр).

Зворотний хід виконується послідовно: на нього припадає лише `O(n²)` операцій проти `O(n³)` у прямому ході.

## Запуск

```
cabal run gauss                    # меню: ввести систему з клавіатури або виміряти час
cabal run gauss -- example.txt     # розв'язати систему з файлу
```

Без cabal:

```
ghc -O2 -threaded -rtsopts "-with-rtsopts=-N" -iapp -isrc app/Main.hs -o gauss
./gauss example.txt
```

Формат файлу: у першому рядку `n`, далі `n` рядків по `n + 1` числу (коефіцієнти і вільний член).
Після розв'язання програма друкує нев'язку `max|Ax − b|`.

```
$ ./gauss example.txt
  x1 = 2.000000
  x2 = 3.000000
  x3 = -1.000000
Нев'язка max|Ax - b| = 8.882e-16
```

## Вимірювання часу

У режимі 2 програма генерує випадкову систему з діагональною перевагою і відомим розв'язком.
Систему розв'язано послідовно і паралельно для 1, 2, 4, … потоків (`setNumCapabilities`), час
вимірюється через `getMonotonicTime`. Двоядерна машина, `n = 1600`:

```
Метод                     Потоків     Час, с   Прискор.    Похибка x
--------------------------------------------------------------------
Послідовний                     1      2.885       1.00     2.26e-14
Паралельний                     1      3.233       0.89     2.26e-14
Паралельний                     2      1.676       1.72     2.26e-14
```

На 2 потоках прискорення 1.72 раза. Обидва варіанти дають однаковий розв'язок (похибка ~1e−14).
На машині з більшою кількістю ядер прискорення зростає зі збільшенням `n`.
