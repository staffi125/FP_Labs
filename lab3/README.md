# Лабораторна робота №3

Програма обробки тексту підручника з програмування на Haskell.

**Завдання:** слова тексту, що починаються з голосних літер, розсортувати в алфавітному порядку за
першою літерою слова. Табуляції та послідовності пробілів замінюються одним пробілом.

## Типи (`src/Types.hs`)

| Тип           | Значення                                                                   |
|---------------|----------------------------------------------------------------------------|
| `Symbol`      | символ слова: `Letter`, `Digit`, `Apostrophe`, `Hyphen`                    |
| `Word`        | слово — список символів                                                    |
| `Punctuation` | розділовий знак: `Period`, `Comma`, `Colon`, `Question`, `Dash`, `Bracket` … |
| `Element`     | елемент речення: слово, число або розділовий знак                          |
| `Sentence`    | речення (пропозиція) — послідовність елементів до `.`, `?` або `!`         |
| `Text`        | текст — список речень                                                      |

## Алгоритм

1. `squeezeSpaces` у кожному рядку замінює табуляції й серії пробілів одним пробілом.
2. `parseText` розбирає текст на елементи й речення. Апостроф і дефіс усередині слова
   (`об'єктів`, `будь-якому`) лишаються частиною слова.
3. `vowelWordsByInitial`:
   - відбирає слова, перша літера яких голосна (українські `а е є и і ї о у ю я`, латинські `a e i o u`);
   - зводить їх до нижнього регістру й прибирає повтори;
   - стабільно сортує за першою літерою. Слова з однаковою першою літерою лишаються в порядку появи в тексті.
   Порядок літер задано явно: спочатку латиниця, потім українська абетка (`… е є … и і ї …`).
   Сортування за кодами Unicode тут не підходить: у ньому `є`, `і`, `ї` стоять після `я`.

## Запуск

```
cabal run vowel-words -- textbook.txt
```

або

```
ghc -O2 -iapp -isrc app/Main.hs -o vowel-words
./vowel-words textbook.txt
```

```
  А: а, аргумент
  Е: елементів, ефектами

  І: ідея, інший, інструмент, і
  О: основна, описано, обчислення, описує, операцію, оголошення, оператор, одна, об'єктів, операції, обмеження, обробки

```
