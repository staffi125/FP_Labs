# Лабораторна робота №1

Інформаційна система **«Розклад роботи дисплейних класів факультету»** на Haskell з використанням
класів типів (`class` / `instance`). База даних — MySQL.

## Можливості

- розклад аудиторії (планові заняття та час вільного доступу), розклад викладача, розклад групи;
- стан усіх аудиторій на заданий день тижня й час: заняття, вільний доступ або зачинено;
- завантаженість дисплейних класів: години занять і вільного доступу на тиждень, відсоток від
  робочого тижня (пн–сб, 08:00–20:00 = 72 год), кількість справних місць;
- завантаженість робочих місць: кількість сеансів, години роботи, дата останнього сеансу;
- введення, коригування й видалення даних у всіх таблицях;
- перевірки під час збереження: час початку раніше за час завершення; попередження, якщо нове заняття
  перетинається з іншим у тій самій аудиторії або в того самого викладача.

## База даних (7 таблиць)

| Таблиця        | Зміст                                                        |
|----------------|--------------------------------------------------------------|
| `classrooms`   | дисплейні класи: номер, корпус, кількість місць, примітка    |
| `workstations` | робочі місця: аудиторія, інвентарний номер, конфігурація, стан |
| `teachers`     | викладачі                                                    |
| `users`        | користувачі (студенти, лаборанти тощо)                       |
| `lessons`      | розклад планових занять: аудиторія, викладач, група, день, час |
| `open_hours`   | час вільного доступу до аудиторій                            |
| `sessions`     | сеанси роботи користувачів на робочих місцях (завантаженість) |

## Класи типів

| Клас | Методи | Екземпляри |
|------|--------|------------|
| `Record` | `table`, `fields`, `ordering`, `key` + узагальнені `listAll`, `findOne`, `create`, `modify`, `remove` | усі 7 типів |
| `Form` | `fill`, `refill`, `check` (метод за замовчуванням без перевірки) | усі 7 типів |
| `Display` | `display` | усі 7 типів |
| `Conflicts` | `conflicts` (за замовчуванням — дозволити збереження) | усі типи; для `Lesson` — перевірка перетинів |
| `QueryResults`, `QueryParams` (mysql-simple) | перетворення між рядком таблиці й записом | усі 7 типів |

## Структура

```
schema.sql           створення бази display_classes і тестові дані
app/Main.hs          меню
src/Model.hs         типи даних і екземпляри QueryResults / QueryParams
src/Storage.hs       клас Record і узагальнені операції з таблицями
src/Form.hs          клас Form — введення й коригування з клавіатури
src/Display.hs       клас Display
src/Reports.hs       розклади, стан аудиторій, завантаженість, перевірка перетинів
src/Prompt.hs        введення чисел, дат, часу з перевіркою
src/Connection.hs    підключення до MySQL
```

## Запуск

1. Встановити MySQL і бібліотеку клієнта (macOS: `brew install mysql pkg-config`).
2. Створити базу:
   ```
   mysql -u root -p < schema.sql
   ```
3. Зібрати й запустити:
   ```
   cabal update
   cabal run display-classes
   ```
   Параметри підключення задаються змінними середовища `DB_HOST`, `DB_PORT`, `DB_USER`,
   `DB_PASSWORD`, `DB_NAME`. За замовчуванням: `root` без пароля на `localhost:3306`, база `display_classes`.
   ```
   DB_USER=root DB_PASSWORD=secret cabal run display-classes
   ```
